NOTIFICAÇÕES COM O APP FECHADO — passo a passo (feito uma vez só)

Como funciona: o painel avisa um pequeno servidor (Apps Script do Google) quando alguém
manda mensagem ou cria uma demanda; o servidor envia o aviso pelo Firebase para o celular
de quem deve receber, mesmo com o app fechado.

JÁ FEITO: a chave VAPID já está no push-config.js (vapidKey).
NÃO PRECISA de chave de conta de serviço (a organização bloqueia). O script usa o login
de quem o publica (joao@dcoracaohome.com, que é dono do projeto d-coracao).

1) ATIVAR A API DE ENVIO
   console.cloud.google.com > selecione o projeto d-coracao > APIs e serviços > Biblioteca
   > "Firebase Cloud Messaging API" > Ativar. (Confira também que "Cloud Firestore API" está ativa.)

2) CRIAR O APPS SCRIPT
   script.google.com > Novo projeto (conta joao@dcoracaohome.com). Nome: "Push Painel D Coração".
   Cole o arquivo apps-script/Codigo.gs no lugar do conteúdo.
   Configurações do projeto (engrenagem):
     - marque "Mostrar arquivo de manifesto appsscript.json no editor" e cole nele o conteúdo
       de apps-script/appsscript.json;
     - em "Projeto do Google Cloud Platform (GCP)" > Alterar projeto > número do projeto:
       585227824275 (é o projeto d-coracao).

3) AUTORIZAR E TESTAR
   No editor, escolha a função "testarConfiguracao" > Executar > autorize.
   O log deve mostrar "Firestore respondeu 200 — acesso ok".

4) PUBLICAR
   Implantar > Nova implantação > tipo "Aplicativo da Web"
     Executar como: Eu     Quem pode acessar: Qualquer pessoa
   Copie a URL que termina com /exec.

5) LIGAR NO PAINEL
   Coloque a URL no push-config.js (campo scriptUrl) e publique o painel de novo.

6) CADA PESSOA
   Abrir o painel, permitir notificações e (no iPhone) instalar o app na tela de início.
   Em Ajustes deve aparecer "Ativadas — também chegam com o app fechado".

Se mexer no Codigo.gs depois: Implantar > Gerenciar implantações > editar > Nova versão.
Sem o servidor configurado, o painel funciona normal (avisos só com o painel aberto).
